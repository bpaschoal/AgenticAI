**Inconsistent Button Styles Report**

Problem Statement:

The website exhibits inconsistent button styles throughout different sections. Specifically, the "Search", "Log In", and "Sign up" buttons in the top navigation bar have distinct styling compared to the "Check Out" and "Login" buttons in the footer.

Recommended Fixes:

```css
/* Define a global button class */

  background-color: #4CAF50;
  color: #fff;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
}

/* Apply the button class to the inconsistent buttons */

  @extend(.button);
}

  @extend(.button);
}
```
